# Security Policy

## Supported Versions

Only the latest released version receives security fixes.

## Reporting a Vulnerability

Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/jorgsowa/rust-php-parser/security/advisories/new). Do not open a public issue.

Include a minimal PHP input or code sample that reproduces the problem (panics, hangs, or unbounded memory use on untrusted input count as vulnerabilities). Expect an initial response within 7 days.
